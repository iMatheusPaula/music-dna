# whatday

Joguinho pra ajudar a galera a escolher em qual dia ir: 3 dias do Lollapalooza ou 2 do Ame Laroc.

A pessoa acha que tá fazendo um teste de "DNA musical": ouve trechos de música sem nome nem artista e reage com 🔥, 😐 ou ❌. Cada música é de um dia do festival, e no fim o jogo revela qual dia combina mais com ela.

## Rodar

```sh
python3 -m http.server 8000
```

Abre http://localhost:8000 (de preferência com fone).

## Músicas

Ficam no `tracks.js`. As prévias de áudio vêm da API do iTunes, e as faixas foram tiradas dos sets recentes dos DJs (1001Tracklists) e dos hits dos artistas.
